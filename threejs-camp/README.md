# Forest Pause

Three.js 기반의 따뜻한 3D 캠핑 타이쿤 프로토타입입니다. 정해진 퀘스트 순서 없이 원하는 힐링 활동을 골라 즐기고, 캠핑장을 꾸미며 친구들과 대화하는 흐름을 담았습니다.

## 현재 구현된 플레이

- 파스텔 셀 셰이딩의 3인칭 여름 캠핑장과 밀짚모자 캐릭터
- 원근감 있는 산책로, 오두막, 전봇대, 구름, 숲과 모닥불
- 낮/밤 전환
- 텐트 치기, 불멍, 캠핑 요리, 커피, 산책, 풀숲 가꾸기
- 활동 완료에 따른 솔방울·마음 온도·경험치 보상
- 텐트, 의자, 랜턴, 테이블 구매 및 자유 배치
- 친구 접속 상태와 캠프 채팅 데모
- 데스크톱·모바일 반응형 UI

## 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드는 `pnpm build`로 생성합니다.

## 배포

`main` 브랜치에 Push하면 공식 GitHub Pages Actions 워크플로가 자동으로 빌드하고 배포합니다.

- 저장소: <https://github.com/soo7894/mori-camp>
- 서비스: <https://soo7894.github.io/mori-camp/>

시각 자산과 오픈소스 출처는 [SOURCES.md](./SOURCES.md)에 정리되어 있습니다.

## 온라인 기능 확장 지점

현재 채팅과 친구는 프론트엔드 데모 상태입니다. 실제 서비스에서는 인증, 캠핑장 저장, 실시간 위치/채팅, 아이템 인벤토리를 Supabase 또는 별도 게임 서버와 연결하면 됩니다.
