# MORI CAMP

Three.js로 만든 3D 캠핑장 운영·캠핑 체험 게임 프로토타입입니다.

## 게임 흐름

- **운영하기**: 예약을 받고, 텐트·글램핑·편의시설을 건설하고, 시설을 관리합니다.
- **캠핑하기**: 장작 패기, 낚시, 모닥불, 휴식으로 자원과 보상을 얻습니다.
- **직접 캠핑**: 빈 사이트를 고르고 텐트를 펼친 뒤, 폴대를 조립하고 말뚝을 하나씩 박습니다.
- 테이블·의자·버너는 장비를 꺼내 원하는 땅을 직접 클릭해 배치합니다.
- 의자를 클릭해 앉고, 버너를 클릭해 점화·소화하고, 커피를 내려 머그컵을 직접 눌러 마실 수 있습니다.
- 버너로 식사를 준비하고 접시를 눌러 먹은 뒤, 커피를 내리고 안전하게 불을 끕니다.
- 설거지 통을 반복해서 눌러 식기를 닦고 수납함에 정리합니다.
- 랜턴과 화로를 원하는 위치에 설치하고, 조명과 모닥불을 직접 켤 수 있습니다.
- 모닥불 앞에서 불멍한 뒤 텐트에서 잠들어 다음 날 아침을 맞습니다.
- 하루가 끝나면 숙박 수익과 평판이 반영되며 진행 상황은 브라우저에 자동 저장됩니다.

## 실행

Node.js 20 이상과 pnpm이 설치되어 있어야 합니다.

```powershell
pnpm install
pnpm dev
```

## Windows 앱 빌드

```bash
pnpm install
pnpm build:win
```

독립 실행 파일은 `release/MoriCamp-Windows/Mori Camp.exe`에 생성되고, 배포용 압축 파일은 `release/MoriCamp-Windows-1.0.0.zip`에 생성됩니다. 압축을 푼 뒤 `Mori Camp.exe`를 실행하면 개발 서버 없이 플레이할 수 있습니다.

터미널에 표시되는 로컬 주소를 브라우저에서 여세요.

## 배포 빌드

```powershell
pnpm build
pnpm preview
```

주요 구현 파일은 `src/main.js`, `src/world.js`, `src/style.css`입니다.
